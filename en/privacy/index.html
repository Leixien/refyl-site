Privacy

Last updated: 1 November 2026

Refyl does not collect, store on servers, or share personal data. There are no accounts, ads, analytics, tracking or third-party libraries.

Location

In the app it is used only to find nearby stations: it is processed on the phone and never sent anywhere. You can deny the permission and move the map by hand.

Network

The app's only request downloads the public price file (https://leixien.github.io/FuelFinder_DATA/stations.json, served by GitHub Pages). It carries neither your location nor any identifier. Like any web server, GitHub may log the IP address and time of the request under its own privacy statement.

Preferences

Fuel, service mode, sort order and theme stay on the phone.

This website

This site is hosted on GitHub Pages and uses no cookies, analytics, or third-party fonts or scripts. The home page map downloads the same public price file as the app. If you press "Near me", your browser asks for location permission: the position is used only inside the page to work out distances and is never sent anywhere. GitHub may log the IP address and time of visits under its own privacy statement.

If you email us

If you write to contactus@binarybuilders.dev, we use your address and message only to reply. You can ask us to delete the conversation at any time.
