Privacy

Ultimo aggiornamento: 1 novembre 2026

Refyl non raccoglie, non salva su server e non condivide dati personali. Non ci sono account, pubblicità, analytics, tracciamento o librerie di terze parti.

Posizione

Serve solo a trovare i distributori vicini. Viene usata sul telefono e non viene mai inviata a nessuno. Puoi negare il permesso: l'app resta utilizzabile spostando la mappa a mano.

Rete

L'unica richiesta che l'app fa è lo scaricamento del file pubblico dei prezzi (https://leixien.github.io/FuelFinder_DATA/stations.json, servito da GitHub Pages). La richiesta non contiene la tua posizione né identificativi. Come ogni server web, GitHub può registrare indirizzo IP e data della richiesta secondo la propria informativa.

Preferenze

Carburante, self o servito, ordinamento e tema restano sul telefono.

Questo sito

Il sito è ospitato su GitHub Pages. Non usa cookie, analytics né font o script esterni. GitHub può registrare indirizzo IP e data delle visite secondo la propria informativa.

Se ci scrivi

Se mandi un'email a contactus@binarybuilders.dev, usiamo il tuo indirizzo e il contenuto del messaggio solo per risponderti. Puoi chiedere in qualsiasi momento di cancellare la conversazione.
